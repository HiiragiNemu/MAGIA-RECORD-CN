# MAGIA RECORD CN research archive

这是魔法纪录国服客户端与 Web/ADV 复原研究的公开索引仓库。

计划收录：

- 国服客户端逻辑与本地服务器研究代码；
- 国服字体及其在 ADV 界面中的使用证据；
- 对话气泡、字号、布局和页面规格；
- APK、完整资源与大型数据集的 Release 归档清单；
- 可复现的文件路径、大小与 SHA-256 校验值。

## 数据边界

原始研究目录为 `D:\magia\MyProducts\MAGIA RECORD CN`，约 22 GiB、52,574 个文件。
该目录保持只读，本仓库使用独立发布工作树。

以下内容不会公开：

- 玩家个人信息转储；
- 带 UID 的账号数据；
- 玩家覆盖配置和可能包含账号状态的服务器配置；
- 密钥、令牌、签名材料或其他凭据。

超过 GitHub 普通 Git 文件限制的 APK、二进制库、影片和大型数据集不会进入 Git
历史，而是作为 Release 资产发布。大体量资源树也会使用可校验归档，避免生成无法维护的
多 GiB Git 历史。
